## SQL 编写与优化规范

### 一、索引
- 是否在 WHERE / JOIN / ORDER BY 的列上建了索引？
- 是否违反最左前缀原则（复合索引）？
- 是否对索引列做了函数运算（会导致索引失效）？

### 二、查询
- 避免 `SELECT *`，只取需要的列
- 大表分页用「游标/延迟关联」，别用大 `OFFSET`
- 子查询能否改写成 JOIN（性能更好）？
- `EXPLAIN` 看执行计划：有没有全表扫描、临时表、文件排序？

### 三、事务
- 事务范围是否尽量小（别把无关操作包进来）？
- 是否注意了隔离级别与幻读/不可重复读？
- 是否有死锁风险（加锁顺序不一致）？

### 输出要求
指出问题 → 说明为什么慢/危险 → 给出改写后的 SQL。
