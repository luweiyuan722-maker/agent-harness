## C++ 代码审查清单

### 一、内存安全
- [ ] 每个 `new` 是否都有配对的 `delete`（或已换成智能指针）？
- [ ] 裸指针是否有悬垂（指向已释放对象）风险？
- [ ] 数组访问是否有越界可能（尤其 `strcpy`/`sprintf` 这类）？
- [ ] 返回局部对象的引用/指针？
- [ ] 是否遵守 Rule of Three/Five（析构 + 拷贝构造 + 拷贝赋值 + 移动）？

### 二、资源管理
- [ ] 资源是否用 RAII 封装（文件句柄、锁、连接）？
- [ ] 异常路径下资源能否正确释放？
- [ ] 使用 `std::unique_ptr` / `shared_ptr` 是否能替代裸指针？

### 三、并发
- [ ] 共享数据是否都有锁保护？
- [ ] 加锁顺序是否一致（防死锁）？
- [ ] 条件变量是否处理了虚假唤醒？
- [ ] 是否误用 `volatile` 代替原子操作？

### 四、性能
- [ ] 是否有不必要的拷贝（应传 const 引用 / 用移动）？
- [ ] 循环内是否有重复计算或重复分配？
- [ ] 容器的选择是否合理（`vector` vs `list` vs `unordered_map`）？

### 输出要求
按 **严重程度** 排序（严重 → 一般 → 建议），每条给出：位置、问题、为什么危险、怎么改。
